# IIPLA Patent Brokerage — public design preview

Public preview: https://azamghani.github.io/html-portfolio/iipla-patent-brokerage/

This isolated folder hosts the IIPLA-branded patent brokerage landing-page preview requested by Azam Ghani. Existing portfolio pages are unchanged.

`index.html` is the full static interactive page. Its source integrity was checked against the approved artifact. The IIPLA logo is loaded from the canonical IIPLA website asset.

The preview is not a live intake system: it does not submit or store leads. Do not enter confidential patent information or real personal information while testing. Production launch requires approved submission/privacy terms and a connected, validated backend.

The page contains all 32 technology categories, mandatory international telephone validation, and the contact-first / optional-portfolio flow.
