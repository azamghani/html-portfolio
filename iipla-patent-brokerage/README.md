# IIPLA Patent Brokerage — public design preview

Public URL: https://azamghani.github.io/html-portfolio/iipla-patent-brokerage/

## Version 3 — September 22, 2026

**Your patents. More ways to monetize.**

This version presents patent sales, licensing and monetization partnerships as distinct routes, with upfront, hybrid and future-proceeds economics explained separately. It includes portfolio triage, seller-side package preparation, targeted outreach, commercial negotiations and appropriately scoped settlement coordination alongside counsel.

The initial contact form requires a phone number with country code. The optional portfolio step captures an asset list, ownership, existing representation and restrictions, preferred route and payment structure. All 32 technology categories are retained. FAQs clarify seller-paid commissions, defined future proceeds, exclusivity and confidentiality.

## Preview boundaries

The forms remain in **preview mode**. They do not submit or persist leads. Use fictitious information when testing. Do not enter confidential patent information or real personal information. No public asset listing, brokerage appointment or exclusivity commitment is created.

Before collecting real enquiries, connect approved backend endpoints, enforce server validation and access controls, and obtain approved brokerage-specific submission/privacy terms and engagement documents.

## Files and maintenance

`index.html` is the public page. Version 3 was generated from the reviewed v2 page by `build_v3.py` and `v3-refinements.css`, then integrity-checked before publication. The legacy `page-*.txt` transfer files are not the current source; changing them can invoke the legacy v2 publishing workflow. Do not edit or rerun that legacy process for v3 changes.

The existing portfolio homepage and the main IIPLA website are unchanged.
